# Discord 認証Bot

Discordのボタン認証Botです。

## 主な機能

- `/認証パネル` で認証ボタンを設置
- `/チャンネル表示設定` で認証前に見える/見えないチャンネルを設定
- カテゴリ単位で表示設定可能
- `/認証前ロール設定` で認証前ロールを選択
- 認証前ロールの色をHEXで変更可能
- 新規参加者へ認証前ロールを自動付与
- 認証成功時に認証前ロールを外し、認証済みロールを付与
- `/認証前ロール配布` で既存の未認証メンバーにもまとめて付与
- ロール付与/解除後にDiscord APIから再取得して反映を確認
- `/ロール診断` でBotのロール順位・権限・付与可否を確認

## 1. .env を設定

`.env` を開いて設定します。

```env
DISCORD_BOT_TOKEN=BOT_TOKEN_HERE
DISCORD_CLIENT_ID=APPLICATION_ID_HERE
DISCORD_GUILD_ID=SERVER_ID_HERE
VERIFIED_ROLE_ID=VERIFIED_ROLE_ID_HERE
```

## 2. Discord Developer Portal の設定

Botページで **SERVER MEMBERS INTENT** をONにしてください。
新規参加者へ認証前ロールを自動付与するために必要です。

Botには最低限、以下の権限が必要です。

- ロールの管理
- チャンネルの管理
- チャンネルを見る
- メッセージを送信
- 埋め込みリンク

Bot自身の一番上のロールは、認証前ロールと認証済みロールより上に置いてください。

## 3. 起動

`start.bat` をダブルクリックします。
初回は必要なパッケージを自動でインストールします。

## 認証前ロールの設定

Discordで次を実行します。

```text
/認証前ロール設定 ロール:@未認証 色:#FF9900
```

`色` は省略できます。省略した場合、現在のロール色を維持します。

設定確認:

```text
/認証前ロール確認
```

既存の未認証メンバーにも付ける:

```text
/認証前ロール配布
```

## チャンネル表示設定

```text
/チャンネル表示設定
```

状態は次の3種類です。

- 見える（認証前から表示）
- 見えない（認証後に表示）
- 設定解除（元の権限へ戻す）

設定をまとめて反映:

```text
/認証権限反映
```

認証パネル設置:

```text
/認証パネル
```


## ロールが反映されない場合

Discordで `/ロール診断` を実行してください。Botの最高ロールより認証ロール/認証前ロールが下にあるか、Botに「ロールの管理」があるかを確認できます。

認証ボタンでは、付与後にメンバー情報をDiscord APIから再取得し、ロールが実際に反映されたことを確認してから「認証完了」と表示します。
